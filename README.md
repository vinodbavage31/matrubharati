## ❝ The Vision Behind This Project

> *"Discipline is the bridge between goals and accomplishment."*

In the villages and towns around Bidar district, thousands of capable children never get the right environment to reach their potential. Not because they lack talent — but because they lack access to **structured, expert, and focused preparation.**

**Matru Bharati** was built to close that gap.

This platform is the digital presence of Matru Bharati Coaching Classes — a residential institution that prepares students from Class 3 to Class 10 for India's most prestigious competitive entrance examinations: Sainik School, Navodaya Vidyalaya, Kittur Rani Chennamma Schools, Morarji Desai Residential Schools, and National Military Schools.

## 🚀 Getting Started (Dev)

### Prerequisites

```bash
Node.js >= 18.x
npm >= 9.x  (or yarn / pnpm)
```

### 1. Clone the Repository

```bash
git clone https://github.com/your-username/matru-bharati.git
cd matru-bharati
```

### 2. Install Dependencies

```bash
npm install
```

### 3. Configure Environment Variables

```bash
cp .env.example .env.local
```

Fill in the values in `.env.local`:

```env
NEXT_PUBLIC_SITE_URL=http://localhost:3000
NEXT_PUBLIC_GA_ID=your_google_analytics_id
NEXT_PUBLIC_GOOGLE_MAPS_KEY=your_maps_embed_key
CONTACT_FORM_ENDPOINT=your_form_endpoint
WHATSAPP_NUMBER=919611915336
```

### 4. Run the Dev Server

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

### 5. Production Build

```bash
npm run build
npm start
```

## 🤝 Contributing

Contributions that serve the mission of helping students in Bidar district are welcome.

### How to Contribute

- 🐛 **Bug Reports** — Found something broken? Open an issue with details.
- 💡 **Feature Ideas** — Suggestions for better parent/student experience.
- 🌐 **Localization** — Help translate content to Kannada or Urdu for local reach.
- 🎨 **UI Improvements** — Design enhancements that improve usability on mobile.

### Contribution Flow

```bash
# 1. Fork the repository
# 2. Create a feature branch
git checkout -b feature/your-feature-name

# 3. Commit your changes clearly
git commit -m "feat: describe what you built and why"

# 4. Push and open a Pull Request
```
